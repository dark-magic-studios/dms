description: Read the bundled Next.js 16 docs before writing any Next.js code
---

Next.js 16.2.6 has breaking changes versus common training data. Before writing or
changing routing, metadata, caching, data fetching, or config code, read the relevant
guide in `node_modules/next/dist/docs/` and heed deprecation notices. Do not code
Next APIs from memory.
